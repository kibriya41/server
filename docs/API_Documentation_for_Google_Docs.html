E-Commerce REST API Documentation

Project Name: SCIC / EJP-13 E-Commerce Backend REST API

Production Live URL: https://ecommerce-api-4z3n.onrender.com/api

Local Base URL: http://localhost:5000/api

GitHub Repository: https://github.com/kibriya41/server

1. Standard API Response Structure

Success Response Format

{
  "success": true,
  "message": "Operation completed successfully",
  "data": {}
}

Success Response with Pagination

{
  "success": true,
  "message": "Items retrieved successfully",
  "data": [],
  "pagination": {
    "page": 1,
    "limit": 10,
    "total": 25,
    "totalPages": 3
  }
}

Error Response Format

{
  "success": false,
  "message": "Error description message"
}

2. API Endpoints Overview

Module Method Endpoint Access Level Description
Health GET /api/health Public Check server status
Auth POST /api/auth/register Public Register new user account
Auth POST /api/auth/login Public Authenticate user & get JWT
Auth GET /api/auth/me Authenticated Get current logged-in profile
Users GET /api/users Admin Get list of all users
Users GET /api/users/:id Owner / Admin Get single user profile by ID
Users PATCH /api/users/:id Owner / Admin Update user profile
Users PATCH /api/users/:id/role Admin Change user role (USER / ADMIN)
Users DELETE /api/users/:id Admin Soft delete user account
Categories GET /api/categories Public Get all categories
Categories GET /api/categories/:id Public Get category details by ID
Categories POST /api/categories Admin Create new product category
Categories PATCH /api/categories/:id Admin Update category details
Categories DELETE /api/categories/:id Admin Soft delete category
Products GET /api/products Public List products (filter/search/paginate)
Products GET /api/products/:id Public Get product details by ID
Products POST /api/products Admin Create new product
Products PATCH /api/products/:id Admin Update product details
Products DELETE /api/products/:id Admin Soft delete product
Reviews POST /api/products/:productId/reviews User Add rating & review for product
Reviews GET /api/products/:productId/reviews Public Get reviews for a product
Reviews PATCH /api/reviews/:id Owner / Admin Update existing review
Reviews DELETE /api/reviews/:id Owner / Admin Soft delete review
Orders POST /api/orders User Place new order
Orders GET /api/orders User / Admin Get user's orders or all orders
Orders GET /api/orders/:id Owner / Admin Get order details by ID
Orders PATCH /api/orders/:id/status Admin Update order status (PENDING -> SHIPPED)
Orders DELETE /api/orders/:id Admin Soft delete order

3. Detailed Endpoint Specs

User Registration

Endpoint: POST /api/auth/register

Request Body:

{
  "name": "John Doe",
  "email": "john@example.com",
  "password": "Password123!"
}

Expected Response (201 Created):

{
  "success": true,
  "message": "Registration successful",
  "data": {
    "user": {
      "id": "cm7a1b2c30000abc123def456",
      "name": "John Doe",
      "email": "john@example.com",
      "role": "USER"
    },
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}

User Login

Endpoint: POST /api/auth/login

Request Body:

{
  "email": "john@example.com",
  "password": "Password123!"
}

Expected Response (200 OK):

{
  "success": true,
  "message": "Login successful",
  "data": {
    "user": {
      "id": "cm7a1b2c30000abc123def456",
      "name": "John Doe",
      "email": "john@example.com",
      "role": "USER"
    },
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}

Create Product (Admin Only)

Endpoint: POST /api/products

Headers: Authorization: Bearer <ADMIN_JWT_TOKEN>

Request Body:

{
  "name": "Wireless Noise-Canceling Headphones",
  "description": "Premium over-ear Bluetooth headphones with active noise cancellation",
  "price": 149.99,
  "stock": 50,
  "image": "https://example.com/headphones.jpg",
  "categoryId": "cm7cat0010000xyz789def012"
}

Create Order (User)

Endpoint: POST /api/orders

Headers: Authorization: Bearer <USER_JWT_TOKEN>

Request Body:

{
  "items": [
    {
      "productId": "cm7prod0010000abc987xyz321",
      "quantity": 2
    }
  ]
}
